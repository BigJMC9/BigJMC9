## Featured Projects

### [JCOS](https://github.com/BigJMC9/JCOS)

A from-scratch **x86-64 microkernel operating system** written primarily in C and assembly.

JCOS explores capability-based security, isolated Ring 3 services, bounded IPC, service supervision, memory protection, native hardware support, and moving operating-system policy out of the kernel.

Current functionality includes:

- UEFI x86-64 boot
- Physical and virtual memory management
- Ring 3 userspace
- Capability-based authority
- IPC and versioned service protocols
- Preemptive scheduling
- ELF program launching
- Managed service recovery
- ACPI + APIC/IOAPIC
- AHCI storage
- GPT partition support
- xHCI USB host support
- USB HID keyboards
- Userspace console and applications
- Bare-metal and stress-test infrastructure

**C · x86-64 Assembly · UEFI · Microkernel · OSDev**
